Local-first by design

Kontrol tetap ada di tanganmu.

LocSRV dirancang untuk mengelola development environment tanpa menjadikan project dan credential sebagai produk sampingan.

Baca kebijakan privasi

Download terverifikasi

Package menggunakan HTTPS dan checksum SHA-256 yang ditentukan katalog.

Perubahan sistem selalu terlihat

Hosts, local CA, penghapusan data, dan public tunnel membutuhkan konfirmasi.

Credential memakai penyimpanan Windows

Password database dan token tunnel disimpan melalui Windows Credential Manager.

Tanpa telemetry publisher

Tidak ada iklan, akun cloud wajib, atau pengiriman source code ke server LocSRV.

Buka pusat dukungan
Apakah LocSRV membutuhkan Docker?

Tidak. LocSRV menjalankan runtime dan service Windows secara native di dalam struktur direktori yang dikelolanya.

Apakah Apache, PHP, dan database sudah ada di installer?

Tidak. Package pihak ketiga diunduh hanya setelah kamu memilih Install, lalu diverifikasi sebelum diekstrak dan diaktifkan.

Di mana LocSRV menyimpan data?

Build terinstal menyimpan data yang dapat berubah di folder data di bawah direktori instalasi. Lokasi aktual selalu ditampilkan pada wizard dan Settings.

Apakah domain lokal dan HTTPS mengubah Windows?

Jika kamu mengaktifkannya, LocSRV dapat memperbarui hosts file dan menambahkan local CA ke certificate store pengguna. Tindakan tersebut selalu meminta konfirmasi lebih dahulu.

Apakah project bisa dibagikan ke internet?

Bisa melalui Cloudflare Quick Tunnel. Fitur ini bersifat opsional, membutuhkan cloudflared, dan menampilkan peringatan sebelum endpoint lokal dibuka untuk akses publik.

Siap merapikan local development?

Bangun web. Bukan setup environment.
