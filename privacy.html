00

Ringkasan privasi

LocSRV tidak mewajibkan akun, tidak memuat iklan, serta tidak menyertakan analytics atau telemetry yang dioperasikan penerbit.

File project, konfigurasi, credential, log, sertifikat lokal, isi database, dan aktivitas terminal tidak dikirim ke penerbit LocSRV atau server yang dikendalikan penerbit.

Komunikasi jaringan hanya terjadi ketika diminta pengguna atau dibutuhkan fitur yang diaktifkan, seperti mengunduh package, terhubung melalui SSH, memeriksa pembaruan, atau menjalankan Cloudflare Tunnel.

01

Ruang lingkup

Kebijakan ini berlaku untuk aplikasi desktop LocSRV di Windows serta website dan halaman dukungan resminya.

Package dan layanan yang kamu pilih untuk dipasang atau dihubungkan memiliki kebijakan privasi dan ketentuannya sendiri.

02

Informasi yang diproses LocSRV secara lokal

LocSRV memproses dan menyimpan informasi di perangkatmu untuk mengelola development environment lokal. Bergantung pada fitur yang digunakan, informasi ini dapat mencakup:

  • Preferensi aplikasi, termasuk bahasa, tema, lokasi workspace, terminal, editor, startup, pola domain, pembaruan, dan retensi log.
  • Nama dan lokasi project, domain development lokal, konfigurasi web server, runtime, port, serta development profile.
  • Environment variable pada development profile beserta nilainya; semuanya tetap berada di file profile lokal.
  • Metadata package, progres download, integrity hash, runtime yang terpasang, dan konfigurasi development tool.
  • Output service lokal, log aplikasi, laporan diagnostik yang disanitasi, backup database, serta file dari fitur yang kamu gunakan.
  • Nama profile SSH, hostname atau alamat IP, port, username, metode autentikasi, dan lokasi private key lokal opsional.
  • Username dan credential database lokal, token Cloudflare Tunnel yang sengaja disimpan, serta sertifikat HTTPS lokal.

Credential dan private key

  • Password database dan token Cloudflare Tunnel disimpan melalui Windows Credential Manager.
  • Password SSH dimasukkan secara interaktif melalui Windows OpenSSH dan tidak disimpan LocSRV.
  • LocSRV hanya menyimpan lokasi private key SSH yang dipilih; isinya tidak disalin atau diunggah.
  • Private key sertifikat yang dibuat secara lokal tetap berada di perangkat dan tidak dikirim ke penerbit.
03

Informasi yang tidak dikumpulkan LocSRV

LocSRV tidak dengan sengaja mengirim hal berikut kepada penerbit:

  • Source code project atau konten websitemu.
  • Isi database atau backup database.
  • Perintah terminal atau isi sesi SSH.
  • Password, access token, atau private key.
  • Sertifikat lokal atau private key sertifikat.
  • Kontak, foto, kamera, mikrofon, atau lokasi presisi.
  • Advertising identifier atau data pelacakan lintas aplikasi.

LocSRV tidak menjual informasi pribadi dan tidak membagikannya kepada jaringan iklan atau data broker.

04

Komunikasi jaringan dan pihak ketiga

Beberapa fitur LocSRV berkomunikasi dengan sistem pihak ketiga untuk menyediakan fitur yang kamu minta atau aktifkan.

Download package

Saat kamu memasang package, LocSRV mengunduhnya melalui HTTPS dari penerbit atau distribution host yang tercantum. Host tersebut dapat memproses informasi jaringan biasa seperti alamat IP, waktu request, dan protocol header. LocSRV memverifikasi package dengan checksum SHA-256 sebelum instalasi.

Pembaruan

Jika signed update dikonfigurasi dan pemeriksaan otomatis aktif, LocSRV dapat menghubungi update service melalui HTTPS. Pemeriksaan otomatis dapat dinonaktifkan dari pengaturan.

Cloudflare Tunnel

Jika kamu menjalankan public tunnel, LocSRV membuka cloudflared dan mengirim traffic melalui Cloudflare. Penanganannya mengikuti Kebijakan Privasi Cloudflare .

Koneksi SSH

Saat sesi SSH dimulai, Windows OpenSSH terhubung langsung ke server tujuan. Server dan operatornya dapat memproses data autentikasi, perintah, dan traffic sesuai kebijakan mereka.

Layanan Microsoft dan GitHub

Microsoft dapat memproses informasi saat kamu memperoleh LocSRV dari Microsoft Store atau saat Windows memasang pembaruan. Website dan repository dukungan LocSRV dihosting GitHub; masing-masing layanan tunduk pada kebijakan privasinya sendiri.

05

Akses perangkat dan perubahan sistem

LocSRV membutuhkan akses ke file dan proses lokal untuk berfungsi sebagai pengelola development environment. Bergantung pada tindakanmu, LocSRV dapat:

  • Membuat, membaca, memperbarui, dan menghapus file di direktori LocSRV.
  • Membaca atau memperbarui direktori project yang kamu pilih.
  • Menjalankan dan menghentikan proses development lokal.
  • Mengunduh dan memasang runtime yang kamu pilih.
  • Mengubah Windows hosts file setelah konfirmasi dan elevation prompt.
  • Membuat serta mempercayai local development CA setelah konfirmasi.
  • Menambah atau menghapus startup entry pengguna saat pengaturannya diubah.
  • Membuka service lokal ke publik hanya setelah konfirmasi tunnel.

LocSRV tidak memasang device driver non-Microsoft. Development server berjalan sebagai user-mode process, bukan Windows NT service.

06

Log dan diagnostik

Log aplikasi dan service disimpan secara lokal. LocSRV melakukan sanitasi untuk menyamarkan field umum seperti password, token, secret, dan authorization dari informasi diagnostik.

Laporan diagnostik dan export log tidak diunggah otomatis. File hanya meninggalkan perangkat jika kamu membagikannya secara manual.

Tinjau file diagnostik sebelum dibagikan. Lokasi project, hostname, detail konfigurasi, dan output tool pihak ketiga masih dapat mengidentifikasi environment-mu.
07

Retensi dan penghapusan

Data LocSRV tetap berada di perangkat hingga kamu menghapusnya melalui kontrol aplikasi atau menghapus file terkait. Pengaturan retensi dapat otomatis menghapus log atau backup lama.

Menghapus instalasi aplikasi mungkin tidak menghapus project, database, backup, credential, sertifikat, atau data development buatan pengguna. Tinjau dan hapus item tersebut secara manual saat tidak lagi dibutuhkan.

Credential database dan token tunnel dapat dihapus melalui LocSRV. Informasi lokal lainnya dapat dihapus melalui tindakan yang relevan atau dengan menghapus data directory setelah semua proses LocSRV dihentikan.

08

Komunikasi dukungan

Jika kamu menghubungi penerbit, mengirim issue, menulis Store review, atau membagikan laporan diagnostik, konten tersebut diproses hanya untuk merespons, menyelidiki masalah, menjaga keamanan, dan memperbaiki LocSRV.

GitHub Issues bersifat publik. Jangan kirim password, private key, access token, source code privat, export database, atau informasi rahasia lainnya.

09

Privasi anak

LocSRV adalah developer tool dan tidak ditujukan secara khusus untuk anak-anak. Penerbit tidak dengan sengaja mengumpulkan informasi pribadi anak melalui aplikasi.

10

Perubahan kebijakan

Kebijakan ini dapat diperbarui ketika fitur atau metode distribusi LocSRV berubah. Tanggal berlaku di bagian atas halaman akan diperbarui jika ada perubahan material.
