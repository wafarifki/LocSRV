LocSRV for Windows

Privacy Policy

This Privacy Policy explains how the LocSRV Windows desktop application handles information when you install and use it.

Publisher: Wafa Rifqi Effective date: August 11, 2026 Application: LocSRV

Privacy summary

LocSRV does not require a LocSRV account and does not include advertising or publisher-operated analytics or telemetry.

Project files, configuration, credentials, logs, local certificates, database content, and terminal activity are not transmitted to the LocSRV publisher or to a server controlled by the publisher.

Network communication occurs when requested by the user or when required by an enabled feature, such as downloading development packages, connecting through SSH, checking for updates, or starting a Cloudflare Tunnel.

1. Scope

This policy applies to the LocSRV Windows desktop application and its official website and support pages.

Software packages and services that you choose to install or connect to have their own privacy policies and terms.

2. Information LocSRV processes locally

LocSRV processes and stores information on your device so that it can manage your local development environment. Depending on the features you use, this may include:

  • Application preferences, including language, theme, workspace paths, terminal and editor preferences, startup preferences, domain patterns, update preferences, and log-retention settings.
  • Project names, local filesystem paths, local development domains, web-server configuration, runtime selections, port assignments, and development profile settings.
  • Development-profile environment variables and their values. These values remain in locally stored profile files.
  • Package metadata, download progress, integrity hashes, installed runtime records, and configuration files for local development tools.
  • Local service output, application logs, sanitized diagnostic reports, database backups, and other files created through features you use.
  • SSH profile names, server hostnames or IP addresses, ports, usernames, authentication method, and an optional local private-key path.
  • Local database usernames and credentials needed to administer databases you create through LocSRV.
  • Cloudflare Tunnel credentials when you explicitly save a tunnel token.
  • Locally generated certificate-authority files, project certificates, and private keys used for local HTTPS development.

Credentials and private keys

  • Database passwords and Cloudflare Tunnel tokens are stored using Windows Credential Manager.
  • SSH passwords are entered interactively through Windows OpenSSH and are not saved by LocSRV.
  • LocSRV stores only the selected SSH private-key path. It does not copy or upload the private-key contents.
  • Locally generated certificate private keys remain on the device and are not transmitted to the publisher.

3. Information LocSRV does not collect

LocSRV does not intentionally send the following to the publisher:

  • Your project source code or website content.
  • Your database contents or database backups.
  • Your terminal commands or SSH session contents.
  • Your passwords, access tokens, or private keys.
  • Your local certificates or certificate private keys.
  • Your contact list, photos, camera, microphone, or precise location.
  • Advertising identifiers or cross-application tracking data.

LocSRV does not sell personal information and does not share information with advertising networks or data brokers.

4. Network communication and third parties

Some LocSRV features communicate with third-party systems. These connections are made to provide a feature requested or enabled by you.

Package downloads

When you choose to install a package, LocSRV downloads it over HTTPS from its listed publisher or distribution host. The receiving host may process ordinary network information such as your IP address, request time, and protocol headers. LocSRV verifies downloaded packages against the configured SHA-256 checksum before installation.

Updates

If signed updates are configured and automatic update checks are enabled, LocSRV may contact the configured HTTPS update service to obtain release metadata and update files. You can disable automatic update checks in the application settings.

Cloudflare Tunnel

If you explicitly start a public tunnel, LocSRV launches cloudflared and sends traffic through Cloudflare. Website requests made through the public tunnel are processed by Cloudflare and forwarded to the local service you selected.

Cloudflare's handling of this traffic is governed by its Privacy Policy.

SSH connections

When you start an SSH session, Windows OpenSSH connects directly to the server address you configured. The destination server and its operator may process authentication data, commands, and session traffic according to their own policies.

Microsoft services

Microsoft may process information when you obtain LocSRV through the Microsoft Store, when Windows checks or installs application updates, or when the installer obtains the Microsoft Edge WebView2 Runtime.

Microsoft may provide the publisher with Store reports such as aggregated acquisition, usage, health, ratings, reviews, and application diagnostic information. This processing is controlled by Microsoft and applicable Windows privacy settings. See the Microsoft Privacy Statement .

GitHub

The LocSRV website and support repository are hosted by GitHub. GitHub may process normal website request information when you visit these pages. See the GitHub General Privacy Statement .

5. Device access and system changes

LocSRV needs access to local files and processes to perform its purpose as a development-environment manager. Depending on your actions, it may:

  • Create, read, update, and delete files within LocSRV directories.
  • Read or update project directories selected by you.
  • Start and stop local development processes.
  • Download and install development runtimes selected by you.
  • Modify the Windows hosts file after confirmation and a Windows elevation prompt.
  • Create and trust a local development certificate authority after your confirmation.
  • Add or remove a current-user Windows startup entry when you change the corresponding setting.
  • Expose a selected local service publicly only after explicit tunnel confirmation.

LocSRV does not install non-Microsoft device drivers. Development servers are run as user-mode processes rather than installed as Windows NT services.

6. Logs and diagnostics

Application and service logs are stored locally. LocSRV applies sanitization intended to redact common password, token, secret, and authorization fields from displayed or exported diagnostic information.

Diagnostic reports and log exports are not automatically uploaded. They leave your device only if you manually share them.

Review diagnostic files before sharing them. Project paths, hostnames, configuration details, and output generated by third-party tools may still identify your environment.

7. Retention and deletion

LocSRV data remains on your device until you remove it using application controls or delete the relevant files. Configured retention settings may automatically remove older logs or backups.

Uninstalling the application may not delete projects, databases, backups, credentials, certificates, or other user-created development data. Review and remove these items manually when you no longer need them.

You can remove saved database credentials and tunnel tokens through LocSRV. Other locally stored information can be removed using the relevant delete action or by deleting the LocSRV data directory after stopping all LocSRV-managed processes.

8. Support communications

If you voluntarily contact the publisher, submit an issue, write a Store review, or send a diagnostic report, the submitted content and your chosen contact information will be processed only to respond to the request, investigate the issue, maintain security, and improve LocSRV.

GitHub Issues are public. Do not post passwords, private keys, access tokens, private source code, database exports, or other confidential information in an issue.

9. Children's privacy

LocSRV is a developer tool and is not directed specifically at children. The publisher does not knowingly collect personal information from children through the application.

This policy may be updated when LocSRV features or distribution methods change. The effective date at the top of this page will be updated when material changes are published.
